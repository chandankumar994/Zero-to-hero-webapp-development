## 1. Introduction to JavaScript

JavaScript is a programming language used to make web pages interactive. It allows you to create dynamic content, control multimedia, animate images, and much more.

***

## 2. Setting Up Your Environment

You only need two things:

- A web browser (like Chrome, Firefox, Edge)
- A text editor (Notepad on Windows, TextEdit on Mac, or any code editor like Visual Studio Code)

***

## 3. Writing Your First JavaScript Code

1. Open your text editor and create a new file named `index.html`.
2. Type the following code:
```html
<!DOCTYPE html>
<html>
<head>
  <title>My First JavaScript</title>
</head>
<body>

<h1>Hello, JavaScript!</h1>

<script>
  alert('Welcome to JavaScript programming!');
</script>

</body>
</html>
```

3. Save the file.
4. Open this file in your web browser by double-clicking it.
5. You will see an alert box pop up saying "Welcome to JavaScript programming!".

***

## 4. Understanding Variables and Data Types

- Variables are containers for storing data.
- You can create a variable using `let` or `const`.
- Common data types: Number, String, Boolean.

Example:

```javascript
let name = "John"; // String
let age = 25;      // Number
let isStudent = true; // Boolean
```


***

## 5. Basic Operators and Expressions

JavaScript supports math operators like:

- Addition: `+`
- Subtraction: `-`
- Multiplication: `*`
- Division: `/`
- Modulus (remainder): `%`

Example:

```javascript
let sum = 10 + 5;  // 15
let product = 4 * 7; // 28
```


***

## 6. Control Structures: Conditional Statements

This allows your program to make decisions:

```javascript
let age = 18;

if (age >= 18) {
  console.log("You are an adult.");
} else {
  console.log("You are a minor.");
}
```


***

## 7. Loops in JavaScript

Loops help repeat code multiple times.

Example with `for` loop:

```javascript
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```


***

## 8. Functions: Reusable Code Blocks

Functions bundle code and run it whenever needed.

Example:

```javascript
function greet(name) {
  console.log("Hello " + name);
}

greet("Alice");
```


***

## 9. Working with Arrays

Arrays hold lists of items:

```javascript
let fruits = ["Apple", "Banana", "Orange"];
console.log(fruits[0]); // Apple
```


***

## 10. Objects in JavaScript

Objects organize data in key-value pairs:

```javascript
let person = {
  name: "John",
  age: 30,
  isStudent: false
};
console.log(person.name); // John
```


***

## 11. Introduction to the Document Object Model (DOM)

DOM lets JavaScript interact with the web page elements.

Example:

```javascript
document.getElementById("demo").innerHTML = "Hello from JavaScript!";
```


***

## 12. Simple Interactive Web Page Example

Create an `index.html` file with:

```html
<!DOCTYPE html>
<html>
<head>
  <title>JavaScript Demo</title>
</head>
<body>

<h2 id="demo">Click the button to change this text</h2>
<button onclick="changeText()">Click me</button>

<script>
function changeText() {
  document.getElementById("demo").innerHTML = "You changed the text!";
}
</script>

</body>
</html>
```

Open it in your browser and try the button.

***
